# 💻 LINQ to SQL Student Management

A simple **Windows Forms application** using **LINQ to SQL** to perform CRUD operations on student records.

---

## 🚀 Features

* ➕ Insert Student
* 📋 View Records
* ✏️ Update Details
* ❌ Delete Record

---

## 🛠️ Tech Stack

* C#
* Windows Forms
* LINQ to SQL
* SQL Server
